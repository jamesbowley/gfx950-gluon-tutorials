# Capped vs auto on held-out and real-model shapes

Generated by `sweep.py score`. Gaps are against the best measured configuration of each shape: on the held-out grid every main configuration and every split count n, on the real-model set the v20 columns that were timed (auto, dp, capped, two-tile). "Within 1.5%" counts shapes no more than 1.5% behind it. "capped, n = 1 as dp" runs data-parallel where capped's split is one program per tile. hybrid(W, D) is capped's pick, except two-tile where there are at least W full waves, `256 // S >= 7` and `d = k-tiles * S / 256 <= D`. "Best of capped, two-tile" is the bound for any rule that chooses between the two. "default (measured)" is v20 with STREAMK_POLICY unset after entry 7 (capped, n = 1 as data-parallel), timed in its own processes.
