## m3

One wave on XCD 0 follows a chain of 4096 dependent loads over distinct 128-byte lines of a 1 MiB buffer (a random cycle); ns per load, median of 10 launches. Helpers set the chain up in the same launch.

| case | chase load | ns per load | min | max | chain correct |
|---|---|---|---|---|---|
| reference: HBM (1 GiB read first) | .cg | 369 | 366 | 372 | True |
| reference: LLC (XCD 1 read the chain first) | .cg | 225 | 222 | 226 | True |
| reference: L2 (the chaser read the chain first) | .cg | 87 | 83 | 90 | True |
| written by XCD 0's other CUs, no cache bits | .cg | 368 | 366 | 375 | True |
| same, no 1 GiB read first (old contents in the LLC) | .cg | 85 | 83 | 88 | True |
| written by XCD 0's other CUs, .cs (sc0 nt) | .cg | 370 | 366 | 375 | True |
| written by XCD 0's other CUs after a pre-read | .cg | 85 | 83 | 89 | True |
| written by XCD 0's other CUs, .wt | .cg | 223 | 219 | 228 | True |
| written by XCD 1 with .wt, read with .cv (v20's path) | .cv | 223 | 221 | 226 | True |
| written by XCD 0's other CUs, chased with default loads | default | 369 | 366 | 372 | True |
