# Memory-bound small-M grid: v27 split against v9_tile data-parallel

v9_tile §14.7's grid: M = BM = 1, 4, 16, 32, N = 4096 / 8192 / 16384, BN = 16 .. 256, BK = 128, K = 8192, bf16, back to back, 2 GB of rotating inputs (weights from HBM). TB/s counts A, B and C once. `dp`: v9_tile with one wave per SIMD (waves_per_eu = 1, as v27); `cap`: v27 as deployed; `all`: v27 one-tile over all 1024 / W programs. Every small tile runs with v9_tile's default waves (one per 64 columns) except 32x64x128, which needs w2 for its LDS to fit 4 / W workgroups per CU.
